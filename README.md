# ☕ CafeServello - Backend (Monólito Modular)

Bem-vindo ao repositório backend do ecossistema **CafeServello**! Esta aplicação foi desenvolvida utilizando a arquitetura de **Monólito Modular** em .NET, combinando a simplicidade de implantação de um monólito com o desacoplamento e a organização de microsserviços.

---

## 📌 Visão Geral & Arquitetura

O projeto adota os princípios do **Domain-Driven Design (DDD)**, **Clean Architecture** e **Monólito Modular**. Cada módulo é isolado e possui suas próprias regras de negócio, casos de uso e persistência de dados.

## 🛠️ Tecnologias Utilizadas

- **Linguagem & Runtime:** C# / .NET 10 
- **Framework Web:** ASP.NET Core Web API
- **Documentação da API:** OpenAPI / Swagger UI
- **Persistência de Dados:** Entity Framework Core
- **Arquitetura & Padrões:**
  - Monólito Modular (*Modular Monolith*)
  - Domain-Driven Design (DDD)
  - CQRS / Clean Architecture
